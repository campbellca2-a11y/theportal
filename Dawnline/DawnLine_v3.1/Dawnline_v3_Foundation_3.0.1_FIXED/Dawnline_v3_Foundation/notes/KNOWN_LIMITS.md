# Known Limits

- Dawnline requires WebGL and hardware-accelerated browser graphics.
- The 4096 × 2048 textures use meaningful GPU memory; very old integrated graphics may run slowly.
- The cloud image is a static artistic layer, not current weather.
- Twilight colors are intentionally more visible than a physically rendered atmosphere would be from orbit.
- Click inspection reports coordinates and solar state, not place names or local time zones.
- Some locked-down workplace browsers may block local files. A normal personal installation of Chrome, Edge, or Firefox should open the application directly.
- The exact rendered appearance still depends slightly on the browser, display calibration, and graphics driver.
